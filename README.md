## Project overview

This IBM Full Stack Development Capstone project develops a car dealership web application. Customers can browse dealers, filter them by state, inspect dealer information and reviews, create an account, and submit a review. The course project integrates Django, React, dealership services, and sentiment analysis.

## Repository layout

- `server/djangoapp/`: Django views, models, URLs, and API integration.
- `server/djangoproj/`: Django project configuration.
- `server/frontend/static/`: Home, About Us, Contact Us, stylesheets, and images.
- `server/frontend/src/`: React UI, including Login and Register components.
- `server/database/`: database-related lab code.

## Setup and implementation status

This fork is based on the IBM course starter template. The README and informational pages are customized for the capstone; API endpoints, databases, tests, and deployment must be implemented and verified as the respective labs are completed. A source file in this repository alone does not establish that the feature has passed its integration test.
